# Conclusiones

* Los backups completos fueron más sencillos de restaurar, ya que cada archivo podía recuperarse de forma independiente.

* Los backups incrementales ocuparon menos espacio a partir del segundo día, pero requirieron aplicar los archivos en orden y depender del backup base.

* Los tiempos de restauración fueron similares debido al pequeño volumen de datos utilizado en la práctica.

* Para esta práctica, el backup completo resultó más conveniente porque el tamaño de la base de datos era reducido y el proceso de recuperación fue más simple.

* La práctica permitió comprobar que ambos métodos pueden recuperar correctamente la información cuando los respaldos se generan y restauran siguiendo el procedimiento adecuado.
